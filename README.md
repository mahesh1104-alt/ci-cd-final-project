# CI/CD Pipeline Final Project: Application Deployment with Tekton & OpenShift

## Project Overview
This project demonstrates an end-to-end continuous integration and continuous delivery (CI/CD) workflow. It integrates automated linting and unit testing via GitHub Actions, native task execution using Tekton, and containerized deployment running on a Red Hat OpenShift cluster.

## Architecture & Tooling
* **Version Control**: Git & GitHub
* **Continuous Integration**: GitHub Actions
* **Code Quality & Verification**: Flake8 (Linting) and Nose (Unit Testing)
* **Pipeline Orchestration**: Tekton Pipelines / OpenShift Pipelines
* **Deployment Platform**: Red Hat OpenShift Container Platform
